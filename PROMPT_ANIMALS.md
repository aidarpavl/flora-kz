# Супер-промпт: раздел «Животные Красной книги Казахстана» (Флора/Фауна Казахстана)

## Роль
Ты — ведущий разработчик и зоолог-систематик проекта https://flora-kz.streamlit.app
(Streamlit + Supabase/PostgreSQL + GitHub `aidarpavl/flora-kz`). Ты расширяешь готовый раздел
«Красная книга» (растения, 387 видов) разделом **«Животные Красной книги»** — 217 видов из
официального перечня редких и находящихся под угрозой исчезновения видов животных РК
(файл `Перечень животных.xls`).

## Исходные данные
Таблица (HTML, сохранённая как .xls), 4 столбца: № п/п · казахское название · латинское · русское.
Между видами — строки-заголовки систематики на трёх языках
(казахский → латынь → русский): «Тип … Класс … Отряд …». Заголовок действует на все
следующие виды до следующего заголовка; более низкие уровни (класс, отряд) сбрасываются, когда
меняется более высокий.

Состав: 82 беспозвоночных (кольчатые черви, моллюски, ракообразные, паукообразные, насекомые) и
135 позвоночных (круглоротые, рыбы, земноводные, пресмыкающиеся, птицы, млекопитающие);
19 таксонов — подвиды (латынь из трёх слов).

## Требования к данным (на каждый вид)
1. **Названия**: рус., каз., латынь — из перечня; исправить опечатки и латинские буквы-двойники
   в кириллице (и наоборот), первая буква заглавная.
2. **Систематика**: царство (Animalia) → тип → класс → отряд → семейство → род → вид → подвид.
   Тип/класс/отряд — из заголовков перечня на 3 языках; семейство и род — из GBIF Backbone
   (`species/match?kingdom=Animalia`), русские/казахские названия семейств — из справочника
   `rb_families`. Ранг `subspecies` для триномиалов, `parent_latin` = биномиал.
3. **Фото**: iNaturalist (taxa.default_photo, с автором и лицензией) → Википедия (pageimages)
   → GBIF (фото из наблюдений, затем любые). Ссылка проверяется перед сохранением.
4. **Описание** на двух языках: русская Википедия (по русскому названию, затем латыни);
   казахская — из kk-Википедии, иначе машинный перевод ru→kk с пометкой; если статьи нет —
   шаблон «вид рода … семейства … отряда …, занесён в Красную книгу РК».
5. **Места обитания**: точки находок в Казахстане из GBIF (`country=KZ`, без гео-ошибок,
   погрешность ≤ 20 км, дедупликация по 0,01°) и из наблюдений iNaturalist в нашей базе.
   Для посетителей координаты округляются до 0,1° (≈10 км) — защита от браконьеров;
   редакторы видят точные.
6. Всё хранится в той же таблице `red_book_species` с полем `kingdom = 'animalia'`
   (растения — `'plantae'`), точки — в `red_book_points`, ареалы — в `red_book_ranges`.

## Интерфейс
- Новая вкладка **«🐾 Животные Красной книги»** — как «Красная книга» растений:
  каталог карточек (фото, название, латынь, класс/отряд/семейство, число точек),
  поиск, фильтр по категории, общая карта находок, фильтр по области/природной зоне.
- Клик по карточке → **страница животного** (как страница растения): фото, систематика
  (тип, класс, отряд, семейство, род, вид), карта, описание, места обитания, меры охраны.
- Кнопка **«✏️ Редактировать»** справа от названия → код редактора → на той же странице:
  фото с компьютера, точки на карте карандашом, таблица точек, описание
  (Википедия / вставка / перевод рус↔каз), систематика → **«💾 Сохранить»** (заменяет прежнее).
- Всё на двух языках (RU/KZ), без упоминаний и ссылок iNaturalist в интерфейсе.

## Распознавание по фото (при добавлении наблюдения)
- Растения: Pl@ntNet API (`my-api.plantnet.org/v2/identify/all`), ключ в Secrets
  `PLANTNET_API_KEY` (бесплатно, 500 запросов/сутки) — топ-5 видов с вероятностью,
  выбор заполняет форму, вид сопоставляется со справочником базы.
- Животные: подключаемый сервис с ключом (например, iNaturalist Computer Vision по токену
  `INAT_API_TOKEN`); без ключа кнопка распознавания скрыта.

## Качество
- Перед загрузкой — проверка: 217 видов, нет дублей латыни, у каждого есть тип/класс/отряд.
- После загрузки — отчёт: сколько видов с фото, описанием (ru/kk), точками.
- Не превышать лимит БД 500 МБ (бесплатный Supabase): не более 300 точек на вид.
